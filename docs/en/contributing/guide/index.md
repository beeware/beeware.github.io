# Contribution guide

/// note | Project-specific contribution guides

This guide describes BeeWare's general contribution process. Some projects have their own
contribution guides with additional requirements:

* [Briefcase](https://briefcase.beeware.org/en/stable/how-to/contribute/)
* [Toga](https://toga.beeware.org/en/stable/how-to/contribute/)
* [Rubicon Objective-C](https://rubicon-objc.beeware.org/en/stable/how-to/contribute/)

If the repository you want to contribute to is not on this list, follow the contribution
guide for the most relevant project. For example, if you want to work on a Briefcase
template repository, follow the Briefcase guide.
